# Outputs do workflow

Cada subdiretório representa uma execução do workflow
`input -> planejamento -> execução -> saída`.

Os arquivos são evidências da tarefa: entrada normalizada, plano, alterações,
revisão e resumo final. Eles devem registrar também falhas e pendências, não apenas
execuções concluídas.

Consulte `docs/agentic-workflow.md` para criar e validar uma execução.
